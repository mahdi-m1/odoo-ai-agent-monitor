# دليل المستخدم

## الواجهة الرئيسية

- عرض حالة Odoo و Claude.
- إضافة شركة أو شخصية للمراقبة.
- جدول الجهات الحالية.

## الدردشة

أوامر جاهزة:

| الأمر | الوظيفة |
|--------|---------|
| مساعدة | قائمة الأوامر |
| قائمة | الجهات المراقبة |
| حالة | فحص الاتصالات |
| أضف شركة: الاسم، الدولة | إنشاء شريك شركة |
| أضف شخص: الاسم، الشركة، المنصب | إنشاء شخص |
| تقرير | تقرير أسبوعي كامل |
| راقب أخبار | مسح وتسجيل أخبار |
| راقب تعيينات | مسح تعيينات/ترقيات |
| عدّل 12: phone=+973... | تحديث حقول شريك |

أي نص آخر يُمرَّر إلى Claude مع سياق القائمة من Odoo.

## التقارير

- تلقائية: يوم الأحد 08:00 (قابل للتعديل في `.env`).
- يدوية: من لوحة التحكم أو أمر «تقرير».

## نطاق المراقبة

يُحدد بمن تضيفه أنت. الشركات العالمية تُراقب إذا أُضيفت عبر الواجهة؛ التركيز الجغرافي للمصادر الافتراضية على البحرين والخليج.

# وثيقة تسليم مشروع التخرج
## Odoo AI Agent Monitor — مطابقة المتطلبات بنداً بنداً

**النظام المستهدف:** Odoo 20 Enterprise  
**بيئة الوكيل:** LXC  
**LLM:** Claude CLI (اشتراك شهري)  
**المستودع:** https://github.com/mahdi-m1/odoo-ai-agent-monitor

---

## 1. الهدف العام

| # | البند المطلوب | التحقق | أين في المشروع |
|---|---------------|--------|----------------|
| 1.1 | الاعتماد على البرنامج الأساسي Odoo (CRM وجميع التطبيقات اللازمة) | ✅ | Odoo 20 Enterprise خارجي؛ لا يُستبدل |
| 1.2 | طبقة Agent لضمان تطبيق عملي: جمع وإدخال بيانات + تقارير دورية | ✅ | حزمة `agent/` |
| 1.3 | تشغيل المشروع المساعد (بيئة الوكيل) على **LXC** | ✅ | `docs/DEPLOYMENT.md` + `scripts/setup_lxc.sh` + systemd |
| 1.4 | واجهة للتواصل مع وكيل الذكاء الاصطناعي | ✅ | `web/` (FastAPI) + `python -m agent.main` |

### تفعيل LinkedIn/Social (اختياري)

```env
LINKEDIN_ENABLED=true
LINKEDIN_ACCESS_TOKEN=...
SOCIAL_ENABLED=true
SOCIAL_PUBLIC_FETCH=true
```

أمر الدردشة: `راقب تواصل` — معطّل افتراضياً دون مفاتيح.

## 5. سيناريو تجريبي للجنة

1. `.env` + API Key على Odoo 20 Enterprise  
2. `uvicorn web.app:app --port 8080`  
3. إضافة شركة من الواجهة  
4. (اختياري) تفعيل Social + رابط LinkedIn  
5. `راقب أخبار` ثم `تقرير`  
6. إظهار Activity في Odoo + ملف في `reports_output/`
